# 更新协议

正式 Release 包含 `xiangfeng-v<版本>.exe`、兼容固定下载链接的相同程序副本 `xiangfeng.exe` 和 `update.json`。版本 EXE 使用中文显示标签 `相逢-v<版本>.exe`；本机分享副本也使用中文文件名。GitHub 实测会去除资产文件名中的中文，因此清单必须指向实际英文版本文件，不能根据显示标签拼接 URL。客户端通过最新正式 Release 的固定 HTTPS 地址读取清单，再下载该版本 EXE。客户端不包含 GitHub 登录令牌，公开下载无需登录。旧版 Release 沿用其原资产名称。

清单字段：

| 字段 | 内容 |
| --- | --- |
| schema | 1 |
| app | PixelSword（内部应用身份） |
| version | 三段数字版本，例如 0.15.2 |
| platform | win-x64 |
| runtimeMajor | 8 |
| downloadUrl | 对应版本 EXE 的完整 HTTPS 地址 |
| sha256 | EXE 的 SHA-256，64 个十六进制字符 |
| bytes | EXE 的字节长度 |
| notes | 简短更新说明 |

客户端不覆盖同版本或降级。下载限时、按流读取，拒绝 HTTP 跳转、大小不符和哈希错误，校验 PE 架构及 Windows 版本元数据，再运行无界面的健康检查。

程序忙于游戏、宏、取色或设置编辑时延后替换。空闲并切回本程序后，由临时更新助手等待旧进程退出，备份并替换当前 EXE，再启动新版。配置、取色和日志不进入替换范围。

分享文件名中的版本号标识下载包。当前自动更新沿用已安装 EXE 的文件名，不会随版本改名；实际运行版本以程序内显示和 Windows 文件版本元数据为准。

0.15.2 发布前在本机通过 306 项离线回归、五组 WPF 界面检查，以及真实助手的升级、备份、重启、失败保护和配置保留测试。尚未在另一台实体电脑验证。

当前通道只分发兼容 .NET 8 / Windows x64 的程序；不自动安装或切换 .NET。升级运行时或更新协议时需另行安排兼容迁移。
